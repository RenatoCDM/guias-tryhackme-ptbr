# Política de segurança

## Escopo

Os guias e scripts da branch `main` são mantidos neste repositório. Os exercícios descritos devem ser executados somente em ambientes autorizados, como as máquinas de laboratório do TryHackMe.

## Relatando uma vulnerabilidade

Se você encontrar uma falha em um script deste repositório que possa afetar quem o executa, use o canal **Report a vulnerability** da aba **Security** para enviar os detalhes de forma privada, quando disponível. Inclua o caminho do arquivo, a versão ou commit, os passos para reproduzir e o impacto observado.

Não publique exploits, segredos, credenciais ou dados pessoais em issues públicas. Para erros de documentação sem risco de segurança, use os modelos de issue.

O mantenedor analisará o relato e poderá solicitar detalhes adicionais antes de publicar uma correção. Não há promessa de prazo fixo de resposta.
