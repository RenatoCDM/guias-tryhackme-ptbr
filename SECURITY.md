# Política de segurança

## Escopo

Os guias e scripts da ramificação `main` são mantidos neste repositório. Os exercícios descritos devem ser executados somente em ambientes autorizados, como as máquinas de laboratório do TryHackMe.

## Relatando uma vulnerabilidade

Se você encontrar uma falha em um script deste repositório que possa afetar quem o executa, use a opção **Report a vulnerability** (relatar uma vulnerabilidade) da aba **Security** (segurança) para enviar os detalhes de forma privada. Inclua o caminho do arquivo, a versão ou registro de alteração, os passos para reproduzir e o impacto observado.

Não publique códigos de exploração, segredos, credenciais ou dados pessoais em relatos públicos. Para erros de documentação sem risco de segurança, use os modelos de relato.

O mantenedor analisará o relato e poderá solicitar detalhes adicionais antes de publicar uma correção. Não há promessa de prazo fixo de resposta.
