# Código de conduta

Este repositório é um espaço para aprender e trocar sugestões sobre os guias do TryHackMe. Trate outras pessoas com respeito, mesmo quando discordar de uma solução técnica.

## Comportamento esperado

- Faça críticas ao conteúdo, com exemplos e passos para reproduzir o problema.
- Use linguagem respeitosa e acolha pessoas com diferentes níveis de experiência.
- Respeite a privacidade de participantes e não publique credenciais, dados pessoais ou informações de laboratórios de outras pessoas.

Não são aceitos ataques pessoais, assédio, discriminação, ameaças, mensagens indesejadas em massa nem divulgação de dados privados sem autorização.

## Onde se aplica

Este código vale para relatos, propostas de alteração, comentários e outras interações ligadas ao repositório.

## Como relatar um problema

Para conteúdo inadequado que possa ser discutido publicamente, abra um relato com o mínimo de detalhes necessário. Para assédio, ameaças ou exposição de dados pessoais no GitHub, use também a [ferramenta de denúncia do GitHub](https://github.com/contact/report-abuse). Não repita dados sensíveis no relato.

O mantenedor poderá editar ou remover conteúdo inadequado, encerrar discussões e limitar a participação de quem descumprir estas regras. A resposta será proporcional ao caso.
