# Acessibilidade

Os guias usam Markdown com títulos em ordem lógica, listas e blocos de código para facilitar a leitura por tecnologias assistivas. Sempre que uma imagem for necessária para compreender uma etapa, ela deverá ter uma descrição alternativa útil; informações essenciais também devem aparecer em texto.

Os comandos podem exigir terminal, navegador e ferramentas próprias dos laboratórios. A acessibilidade dessas ferramentas e das salas externas depende de seus respectivos fornecedores.

Se encontrar uma barreira de leitura neste repositório, abra um relato e informe o arquivo, a seção, a tecnologia assistiva usada (se quiser compartilhar) e o que dificultou a tarefa. Sugestões de melhoria são bem-vindas.
