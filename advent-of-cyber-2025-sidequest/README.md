# Advent of Cyber 2025 - Side Quests

As Side Quests são salas adicionais da série Advent of Cyber 2025. Cada sala concluída recebe um guia próprio. A chave de acesso da primeira missão pode ser obtida no desafio opcional do [dia 1](../advent-of-cyber-2025/dia-01-linux-cli-shells-bells.md).

| Missão | Sala | Assuntos principais |
| --- | --- | --- |
| Side Quest 1 | [The Great Disappearing Act](./side-quest-01-the-great-disappearing-act.md) | OSINT, API de vídeo e acesso ao sistema do asilo |
| Side Quest 2 | [Scheme Catcher](./side-quest-02-scheme-catcher.md) | Engenharia reversa, falha de heap, FSOP e contêineres |
| Side Quest 3 | [Carrotbane of My Existence](./side-quest-03-carrotbane-of-my-existence.md) | DNS, injeção de prompt, SMTP e API de modelos |
| Side Quest 4 | [BreachBlocker Unlocker](./side-quest-04-breachblocker-unlocker.md) | Código exposto, hashes SHA-1 e desvio de segundo fator |
