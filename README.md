# Guias de resolução TryHackMe em português

Guias de estudo de salas e desafios públicos do TryHackMe, organizados por sala. Os textos descrevem os métodos usados no laboratório e indicam quando uma resposta não pôde ser reproduzida integralmente.

## Guias

- [Advent of Cyber 1 (2019)](./advent-of-cyber-2019/README.md) - 25 dias de fundamentos de segurança, análise de arquivos, aplicações Web, Linux e redes.

## Como usar

Abra a pasta da sala e leia o `README.md`. Substitua `<IP>` pelo endereço da sua própria máquina de laboratório. Os guias contêm respostas e, portanto, **spoilers**. Execute os procedimentos apenas em ambientes autorizados.

Este repositório não é afiliado ao TryHackMe.
